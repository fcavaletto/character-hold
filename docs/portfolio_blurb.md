# Portfolio blurb (AI safety / eval roles)

## Short (paste-ready)

I built **character-hold**, an open evaluation harness and preprint studying whether “character” system prompts do more than matched instructions under social pressure. Using a five-disposition HHH battery, graded yielding, and pre-registered ablations (blank vs character vs plain-order), I find **model-specific T2** (Sonnet cards beat blank; GPT-4.1-mini does not) and a consistent **T3-negative**: disposition framing does **not** beat matched orders. The paper separates folk meanings of “character cards work” (steering / robustness / Q&A usefulness / agency) and only claims chat steering+robustness. Code, freezes, and results: https://github.com/fcavaletto/character-hold

## Skills demonstrated

- Eval design: say / use / graded hold; soft-yield taxonomy  
- Causal-ish ablations: stripped, matched imperative, naturalistic reverse, demand opposite  
- Pre-registration + go/no-go discipline before confirmatory spend  
- Honest negative / heterogeneous results (portfolio signal for safety taste)  
- Reproducible OpenRouter harness, bootstrap CIs, LLM-judge secondary reliability
